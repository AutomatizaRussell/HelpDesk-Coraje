# Backlog de diseño (sin ratificar)

```
ESTADO:  propuestas, NO decisiones aprobadas
CORTE:   03-sep-2026
```

**Qué es este documento:** un área de espera. Contiene diseño elaborado pero **no
ratificado**: no es contrato, no es plan comprometido y **no debe citarse como decisión
aprobada**. Existe para que el trabajo de diseño no se pierda sin contaminar las
especificaciones.

**Cómo sale de aquí:** cuando se ratifique un bloque, se promueve a su documento
propietario y se retira de este archivo. Lo que no se ratifique se descarta. Un bloque
que lleve mucho tiempo aquí probablemente deba descartarse, no acumularse.

**Precedencia:** este documento está **por debajo** de los documentos históricos en el
orden de autoridad. Ante cualquier duda, no manda.

## Contenido actual
